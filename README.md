# 懒人Agent遥控法

**安装本项目，就可以在 Windows 电脑上用遥控器远程操作 Codex 和 Claude Code。**

躺在沙发上，按住小米遥控器的麦克风说出指令，松开后文字自动出现在输入框里；按 OK 发送，用方向键回答 agent 弹出的选项，用音量键翻看长回答，一个键切换 Claude 和 Codex。

支持的遥控器：**小米蓝牙语音遥控器 2 / 2 Pro**。

## 下载

到 [Releases 页面](https://github.com/sumian-buff/xiaomi-remote-agent/releases/latest) 下载 `XiaomiRemoteAgent-*-win-x64.zip`。

## 安装（约 10 分钟）

1. **安装 VB-CABLE 虚拟声卡**：从 [VB-Audio 官网](https://vb-audio.com/Cable/)下载，解压后右键 `VBCABLE_Setup_x64.exe` →「以管理员身份运行」→ 点 Install，然后**重启电脑**。
   遥控器的声音要经过它才能变成电脑上的麦克风。
2. **配对遥控器**：同时按住遥控器的「主页」和「菜单」键几秒，等指示灯闪烁，再到 Windows「设置 → 蓝牙和其他设备 → 添加设备 → 蓝牙」里选择它。
   如果搜不到，把同一页面下方的「蓝牙设备发现」改成「高级」；另外遥控器同一时间只能连一台设备，先在手机、平板或电视上取消配对。
3. **解压并运行**：把 zip 解压到一个固定位置，例如 `D:\懒人Agent遥控法`，双击 `XiaomiRemoteAgent.exe`。
   程序没有数字签名，Windows 可能提示「已保护你的电脑」：点「更多信息 → 仍要运行」。第一次运行时可能还会弹出一次管理员确认，这是为了接管遥控器的返回键，点「是」。
   使用旧版按键接管时，Defender 可能隔离相关程序。RC003 也可使用下方的设备驱动模式。
4. **设置麦克风**：在程序主窗口打开「环境检查」，点「把默认录音设备设为 CABLE Output」。
   只会改「默认设备」，不会改「默认通信设备」，所以微信、会议等通话软件仍然使用你原来的耳机麦克风。
5. **在应用里设置**（见下一节），然后就可以用了。
6. **开机自启（可选）**：右键 `XiaomiRemoteAgent.exe` →「创建快捷方式」，在快捷方式属性的「目标」末尾加上 ` --minimized`，再按 `Win+R` 输入 `shell:startup`，把快捷方式放进打开的文件夹。

> 如果装过 MiVibe Remote：两者不能同时运行。请先从托盘退出 MiVibe，并把它从开机自启里移除。

## 在 Codex 和 Claude 里要做的设置

**Codex**（设置 → 语音输入 / 键盘快捷键）
- 听写快捷键：**长按 Ctrl+D**；麦克风：**CABLE Output**
- 「上一个侧边栏项目」设为 **Ctrl+Shift+F1**，「下一个侧边栏项目」设为 **Ctrl+Shift+F2**（遥控器的左 / 右键用来切换会话）

**Claude**
- 听写快捷键保持默认的**长按 Ctrl+D**。

## 按键

| 遥控器 | 作用 |
|---|---|
| 麦克风（按住说话） | 短句说完松手。长句听到 55 秒的两声提示后，松手并在 1 秒内重新按住，接着说，最后一次松手后统一结束听写。 |
| OK | 发送；在 agent 的选项卡片上时，选中并提交 |
| 电源 | 中断 agent（Esc） |
| 菜单 | 切到 Claude，光标回到输入框 |
| TV | 切到 Codex |
| 上 / 下 | Claude 弹出选项卡片时，第一下进入卡片，之后在选项间移动；输入框为空、没有卡片时，「下」在 Claude 里 = **从最新一条消息分叉**，在 Codex 里 = Tab（采纳 Codex 建议的下一句）；其他时候就是方向键 |
| 左 / 右 | Claude 输入框为空、回复末尾有建议框时，点第一个 / 第二个按钮；其他时候就是方向键（输入框里有字时用来移动光标） |
| 菜单 / TV → 左 / 右 | **切换会话**：先按菜单（Claude）或 TV（Codex），3 秒内按左 / 右 = 上一个 / 下一个会话。可以连按，会逐个切换；Claude 按侧边栏顺序，跨项目，也包括分叉出来的分支 |
| 音量 + / − | 滚动对话（会自动把鼠标移到对话区），按住连续滚 |
| 返回 | 退格，按住连续删除 |
| 主页 | 在当前应用里新建会话（Claude：Ctrl+N，光标自动进入新输入框；Codex：点「新聊天」） |

### 使用提醒

- **建议框出现时，左右键会直接点按钮。** Claude 回复末尾带按钮的建议框出现时，直接按左 / 右会把按钮上的文字当作你的回复发出去。想切换会话，请用「菜单 → 左 / 右」。
- **分叉**（输入框为空时按「下」）是从**最新一条消息**分叉，分叉前先按住音量「−」滚到底部。用来同时试两种想法：分叉 → 在两个会话里分别说不同的情况 → 用「菜单 → 左 / 右」来回切换。不需要的分支在侧边栏右键删除。

## 常见问题

- **RC003 怎样保留返回和音量键？** 从 0.1.25 起，可将 Quarbor Universal 键盘驱动绑定到这一只遥控器的 HID 设备实例。程序在 `%APPDATA%\XiaomiRemoteAgent\xiaomi.json` 中使用 `input_backend` 为 `quarbor`、`quarbor_device_instance` 为该实例的完整 ID。保持现有按键方案，按住音量键连续滚动，按住返回键连续退格。语音继续使用原有 VB-CABLE 和听写快捷键。驱动断开时松开所有按键状态，遥控器恢复后程序自动重连。重新配对导致设备实例改变时，须重新核对绑定和实例 ID。驱动安装器可以恢复原设备驱动。[驱动说明及来源](https://github.com/leowzz/axonkey/blob/v1.9.16/docs/WINDOWS_INPUT.md)

- **说话后没出字**：确认 Claude / Codex 的听写快捷键是「长按 Ctrl+D」，Windows 默认录音设备是 CABLE Output，Codex 里选的麦克风也是 CABLE Output。
- **一句话说不完一分钟，怎么接着说？** 每次按住约 55 秒，电脑会响两声。在遥控器约 60 秒的收音上限前，停一下，松开语音键，在 **1 秒内重新按住**，再继续说。电脑会保持同一次听写，每次听到提示都可以这样接下去。松手时遥控器收不到声音。说完就松手，若这一段已响过提示，程序会等 1 秒再结束听写；短句仍照常结束。
  提示音时间由环境变量 `XIAOMI_REMOTE_AGENT_LIMIT_WARN_S` 控制，默认为 `55`。
- **按键没反应**：遥控器休眠后，按任意键唤醒，等几秒让它重新连上。
- **按键全乱了 / 程序突然没了 / 开机没自动启动**（TV 键打出「`」、菜单键弹出右键菜单、音量键调系统音量）：多半是 **Windows Defender 把程序当成威胁删掉了**，开机启动的快捷方式也会被一起删除。
  原因：为了接管返回键，程序会以管理员权限把 Frida 组件注入系统的驱动进程（WUDFHost）读取按键数据，Defender 的行为分析可能会把它判定为 `Behavior:Win32/DefenseEvasion.A!ml`。这是误报，但是否放行由你自己决定。
  - **放行**：打开「Windows 安全中心 → 病毒和威胁防护 → 保护历史记录」，找到这条记录，在「操作」里选择「还原」或「允许在设备上」，然后重新运行 `XiaomiRemoteAgent.exe`，并检查开机启动的快捷方式是否还在。
  - **不想放行**：可以关闭返回键接管。退出程序，把 `%APPDATA%\XiaomiRemoteAgent\xiaomi.json` 里的 `"hid_report_tap_enabled"` 改成 `false`，再启动。这样就不会再注入系统进程，代价是**返回键可能失效**。
- **想恢复原来的麦克风**：在「环境检查」里点「恢复原录音设备」。
- 配置和日志在 `%APPDATA%\XiaomiRemoteAgent`，主窗口有「打开日志」按钮。

已在以下环境验证（2026-11-17）：Windows 11、小米蓝牙语音遥控器 2 Pro、Claude 桌面版 5.11、Codex 26.1111。

## 开发说明

程序名称是 **Xiaomi Remote Agent**（`XiaomiRemoteAgent.exe`），源码在 [app/](app/)，构建方法见 [app/README.md](app/README.md)，完整设计和踩过的坑见 [AGENTS.md](AGENTS.md)。

工作原理：程序通过低功耗蓝牙连接遥控器，接收它用安卓电视语音协议（ATVV）发来的声音，解码后播放到 VB-CABLE 的 `CABLE Input`，Claude / Codex 再从 `CABLE Output` 听到；同时，程序会在你按住麦克风时一直按住 Ctrl+D，触发应用自带的听写。程序本身不做语音识别。
按键通过 Raw Input 和键盘钩子识别并拦截，只拦截来自遥控器的按键，不影响真键盘；返回键的信号会被 Windows 丢掉，所以借助 Frida Gadget 读取原始 HID 报告。
Claude 选项卡片、建议按钮、窗口切换和滚动定位由随附的 `remote-helper.exe`（UI Automation）完成。应用按 AppID 启动，不经过开始菜单快捷方式。

开发时要注意：从 Claude 内置终端（MSIX 容器）里启动的程序，`%APPDATA%` 会被重定向，正式运行请用资源管理器或开机自启来启动。
